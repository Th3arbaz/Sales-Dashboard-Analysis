# 📊 Sales Dashboard Analysis

## 🛠 Tool Used
Microsoft Power BI

## 📂 Dataset
100,000 Sales Records

## 📌 Overview
This project analyzes sales performance including:
- Revenue
- Profit
- Regional trends
- Sales channels

## 📈 Key KPIs
- Total Revenue
- Total Profit
- Profit Margin %
- Total Units Sold

## 💡 Insights
- Q2 peak revenue
- Seasonal pattern observed
- Balanced online & offline sales
